# Orcaton — დაყენება და პირველი გაშვება (Windows, macOS, Ubuntu)

[English](quickstart.md) · [Deutsch](quickstart.de.md) · [Русский](quickstart.ru.md) · **ქართული**

Orcaton **საკუთარი ფანჯრის მქონე პროგრამაა**: ის ჩვეულებრივი აპლიკაციასავით იხსნება (საკუთარი
ფანჯარა, ხატულა ამოცანების პანელში ან Dock-ში). ბრაუზერი საჭირო არ არის. ქვემოთ ყველაფერი ნაბიჯ-ნაბიჯ
არის აღწერილი, ტერმინალთან მუშაობის გამოცდილების გარეშე: ტერმინალი **მხოლოდ ერთხელ** დაგჭირდებათ —
ერთი ბრძანების ჩასასმელად. შემდეგ Orcaton მალსახმობით ეშვება.

რა გჭირდებათ: პროექტის საქაღალდე თქვენს კომპიუტერზე, ინტერნეტი დაყენების დროს, 10–20 წუთი და დაახლოებით
3 გბ თავისუფალი ადგილი (კომპილატორები და ბიბლიოთეკები აწყობისთვის). დამყენებლებმა შეიძლება ნებართვა
მოგთხოვონ: Windows — ფანჯარა „გსურთ, ამ აპმა თქვენს მოწყობილობაში ცვლილებები შეიტანოს?“ → **დიახ**;
macOS და Ubuntu — თქვენი ანგარიშის პაროლი (აკრეფისას სიმბოლოები არ ჩანს — ეს ნორმალურია). დაყენების
ბრძანების ხელახლა გაშვება უსაფრთხოა: რაც უკვე დაყენებულია, თავიდან აღარ დაყენდება.

> დაყენების სკრიპტები მიმდინარეობას **რუსულად** წერენ (მაგალითად `== 2/3 Сборка ==`,
> ბოლოს `Готово` — „მზადაა“). მათი წაკითხვა საჭირო არ არის: უბრალოდ დაელოდეთ Orcaton-ის ფანჯრის გახსნას.

## Windows 10 / 11
1. **გახსენით PowerShell პროექტის საქაღალდეში.** Explorer-ში გადადით პროექტის საქაღალდეში, თაგვის
   მარჯვენა ღილაკი ცარიელ ადგილზე → **Open in Terminal / ტერმინალში გახსნა** (Windows 11). Windows 10-ში —
   დააჭირეთ **Shift**-ს და მარჯვენა ღილაკი → **Open PowerShell window here**. მოთხოვნის ხაზში პროექტის
   საქაღალდის გზა უნდა ჩანდეს, მაგალითად `PS D:\Projects\Orcaton>`.
2. **შეამოწმეთ, რა არის უკვე დაყენებული.** ჩასვით ბრძანება (ფანჯარაში მარჯვენა ღილაკი ჩასვამს) და დააჭირეთ **Enter**-ს:
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\install.ps1
   ```
   სკრიპტი თავად არაფერს აყენებს: ის მხოლოდ ამოწმებს Go-ს, Node.js-ს, WebView2-სა და Wails CLI-ს. თუ რამე
   აკლია, ის გამოიტანს ბრძანებებს. შეასრულეთ ისინი **სათითაოდ** (თუ დამყენებლის ფანჯრები გამოჩნდება — **დიახ**):
   ```powershell
   winget install --id GoLang.Go -e
   winget install --id OpenJS.NodeJS.LTS -e
   winget install --id Microsoft.EdgeWebView2Runtime -e
   go install github.com/wailsapp/wails/v2/cmd/wails@v2.13.0
   ```
   შემდეგ გახსენით **ახალი** PowerShell-ის ფანჯარა პროექტის საქაღალდეში და ხელახლა შეასრულეთ მე-2 ნაბიჯის ბრძანება.
   FFmpeg აუცილებელი არ არის: თუ ის არ არის, ფანჯარა პირველი გაშვებისას შემოგთავაზებთ მის დაყენებას.
3. **დაყენება და აწყობა.** როცა ყველა ინსტრუმენტი ადგილზეა, შეასრულეთ:
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Run
   ```
   სკრიპტი ააწყობს პროგრამას, შექმნის მალსახმობებს და გახსნის ფანჯარას. გამოჩნდება ხაზები `== 2/3 Сборка ==`
   (აწყობა) და `== 3/3 Установка ==` (დაყენება).
4. **მზადაა**, როცა **Orcaton**-ის ფანჯარა გაიხსნება, ტერმინალში კი მწვანე `Готово` („მზადაა“)
   გამოჩნდება. მალსახმობი **Orcaton** ახლა სამუშაო მაგიდაზე და „დაწყება“ მენიუშია; ტერმინალის დახურვა
   შეიძლება. ამიერიდან — მხოლოდ მალსახმობი.

## macOS (Apple Silicon და Intel)
1. **Homebrew** (პროგრამების მენეჯერი; თუ უკვე გაქვთ — გამოტოვეთ). გახსენით **Terminal** (Spotlight:
   ⌘ + Space → „Terminal“) და გაუშვით ბრძანება საიტიდან <https://brew.sh> (ერთი ხაზი, Mac-ის პაროლს
   მოითხოვს). ბოლოს Homebrew დაწერს „Next steps“ — გაუშვით ნაჩვენები ორი ბრძანება `echo …` და `eval …`.
2. **ტერმინალი პროექტის საქაღალდეში:** აკრიფეთ `cd ` (ჰარით), Finder-იდან გადმოიტანეთ პროექტის
   საქაღალდე Terminal-ის ფანჯარაში და დააჭირეთ **Enter**-ს.
3. **დაყენების ბრძანება:**
   ```bash
   bash scripts/install.sh --run
   ```
   თუ macOS შემოგთავაზებთ **დეველოპერის ხელსაწყოების (Command Line Tools)** დაყენებას — დააჭირეთ
   „Install“-ს, დაელოდეთ დასრულებას და **იგივე ბრძანება კიდევ ერთხელ გაუშვით**.
4. **მზადაა**, როცა **Orcaton**-ის ფანჯარა გაიხსნება. პროგრამა მდებარეობს **~/Applications**-ში
   (მომხმარებლის პროგრამები): იპოვეთ Launchpad-ით ან Spotlight-ით („Orcaton“) და დაამაგრეთ Dock-ში
   (მარჯვენა ღილაკი ხატულაზე → Options → Keep in Dock).

### macOS: მზა პაკეტი (.dmg)
თუ Orcaton გაქვთ ფაილად `Orcaton-<ვერსია>-macos-universal.dmg` (ერთი პაკეტი Apple Silicon-ისა და
Intel-ისთვის; macOS 12 Monterey ან უფრო ახალი), ტერმინალში არაფრის აწყობა ან დაყენება არ არის საჭირო:
1. **დააკოპირეთ პროგრამა.** ორჯერ დააწკაპუნეთ `.dmg`-ზე → გაიხსნება ფანჯარა **Orcaton**-ით და
   **Applications** საქაღალდით → გადაიტანეთ **Orcaton** **Applications**-ზე. შემდეგ ამოაგდეთ დისკი
   (Finder-ის გვერდითი პანელი → ⏏).
2. **პირველი გაშვება.** Orcaton უფასოა და არ არის ხელმოწერილი Apple-ის ფასიანი სერტიფიკატით, ამიტომ macOS
   აჩერებს პირველ გაშვებას. გახსენით Orcaton Applications-დან → შეტყობინება „Apple could not verify…“ (ან
   „cannot be opened“) → **Done** / **OK**. გახსენით **System Settings → Privacy & Security**, ჩამოდით
   „Orcaton was blocked…“-მდე → **Open Anyway** → Mac-ის პაროლი → **Open**. macOS 12–14-ზე საკმარისია:
   მარჯვენა ღილაკი Orcaton-ზე → **Open** → **Open**. ეს საჭიროა ერთხელ (და ხელახლა ახალი ვერსიის შემდეგ).
3. **FFmpeg.** თუ ფანჯარა აჩვენებს **„FFmpeg დაყენებული არ არის“** — დააჭირეთ **„FFmpeg-ის დაყენება“**
   (Homebrew-ით, <https://brew.sh>; Homebrew-ის გარეშე ფანჯარა გეტყვით, რა გააკეთოთ).
4. **ბრძანება ტერმინალში (სურვილისამებრ):** **„პროგრამის შესახებ“ → „ბრძანების სტრიქონი“ → „ტერმინალის
   ბრძანების დაყენება“** (macOS პაროლს მოგთხოვთ). ამის შემდეგ `orcaton` მუშაობს Terminal-ის ახალ ფანჯარაში.

განახლება — გადაიტანეთ ახალი Orcaton Applications-ზე → **Replace**. გადმოწერილი ფაილის შემოწმება:
Terminal-ში `shasum -a 256 Orcaton-…dmg` უნდა აჩვენოს იგივე მნიშვნელობა, რაც გვერდით მდებარე `.sha256` ფაილში.

## Ubuntu 22.04 / 24.04 (და სხვა Linux)
1. **ტერმინალი პროექტის საქაღალდეში:** „ფაილებში“ გახსენით პროექტის საქაღალდე, მარჯვენა ღილაკი ცარიელ
   ადგილზე → **Open in Terminal / ტერმინალში გახსნა**.
2. **დაყენების ბრძანება** (მოითხოვს თქვენს პაროლს — აკრეფისას სიმბოლოები არ ჩანს, ეს ნორმალურია):
   ```bash
   bash scripts/install.sh --run
   ```
   სკრიპტი დააყენებს ფანჯრის ბიბლიოთეკებს (GTK, WebKitGTK), FFmpeg-ს, Go-ს, Node.js-ს და Wails-ს,
   ააწყობს პროგრამას და დაამატებს მალსახმობს.
3. **მზადაა**, როცა **Orcaton**-ის ფანჯარა გაიხსნება. მალსახმობი აპლიკაციების მენიუშია (Super ღილაკი →
   „Orcaton“); შეგიძლიათ რჩეულებში დაამატოთ (მარჯვენა ღილაკი → Add to Favourites).
Fedora და Arch — იგივე ბრძანება (სკრიპტი იყენებს `dnf` / `pacman`-ს).

### Linux: მზა პაკეტი (.deb / .rpm)
თუ Orcaton გაქვთ პაკეტის ფაილად, არაფრის აწყობა არ არის საჭირო. პაკეტების მენეჯერი დააყენებს Orcaton-ს
ყველაფერ საჭიროსთან ერთად: ფანჯრის ბიბლიოთეკებს (GTK 3, WebKitGTK 4.1) და **FFmpeg**-ს თქვენი
დისტრიბუტივიდან (FFmpeg რჩება ცალკე პაკეტად საკუთარი ლიცენზიით). გახსენით ტერმინალი ფაილის საქაღალდეში
და გაუშვით (პაროლს მოგთხოვთ):

| სისტემა | ფაილი | ბრძანება |
|---|---|---|
| Ubuntu 22.04 / 24.04, Debian 12, Linux Mint 21+ | `orcaton_<ვერსია>-1_amd64.deb` | `sudo apt install ./orcaton_<ვერსია>-1_amd64.deb` |
| Fedora 39 ან უფრო ახალი | `orcaton-<ვერსია>-1.x86_64.rpm` | `sudo dnf install ./orcaton-<ვერსია>-1.x86_64.rpm` |

* `./` ფაილის სახელის დასაწყისში აუცილებელია — თორემ apt / dnf პაკეტს ინტერნეტში ეძებს.
* Orcaton ხელმოწერილი არ არის: თუ dnf ხელმოწერის გამო უარს იტყვის, დაამატეთ ბრძანებას `--nogpgcheck`.
* ამის შემდეგ: აპლიკაციების მენიუ → **Orcaton**; ტერმინალში — ბრძანება `orcaton`.
* თუ Orcaton ადრე `bash scripts/install.sh`-ით დააყენეთ, ჯერ ის ასლი წაშალეთ:
  `bash scripts/uninstall.sh` — თორემ მენიუ ძველს გახსნის.
* განახლება — იგივე ბრძანება ახალი ფაილით. ფაილის შემოწმება: `sha256sum -c <ფაილი>.sha256`.

## პირველი სინქრონიზაცია
0. **ფანჯრის ენა:** მარცხენა სვეტის ქვემოთ (გლობუსის ხატულა) აირჩიეთ **ქართული** — წარწერები მაშინვე
   შეიცვლება, არჩევანი დაიმახსოვრება. ქვემოთ ღილაკების სახელები ისეა, როგორც ქართულ ფანჯარაში.
1. **სამონტაჟო პროგრამა:** თითოეული კამერა / ჩამწერი — საკუთარ ტრეკზე; თაიმლაინის ექსპორტი
   (*File → Export → Timeline…*) → **DRT (.drt)** ან **FCP 7 XML V5 (.xml)**.
2. **Orcaton:** დააწკაპუნეთ ბლოკზე **„გადმოიტანეთ XML / DRT ან აირჩიეთ…“** — გაიხსნება ფაილის არჩევის
   ჩვეულებრივი ფანჯარა; აირჩიეთ ექსპორტირებული თაიმლაინი (ან უბრალოდ გადმოიტანეთ ფაილი Orcaton-ის
   ფანჯარაში).
3. თუ მედია იქ აღარ არის, სადაც მონტაჟის დროს იყო, — **+ საქაღალდის დამატება** და აირჩიეთ საწყისი
   ფაილების საქაღალდე (ძებნა სახელით ყველა ქვესაქაღალდეში). შეიძლება მოგვიანებითაც: სინქრონიზაციამდე
   Orcaton თავად გკითხავთ.
4. დააჭირეთ მწვანე ღილაკს **სინქრონიზაცია** (ქვემოთ მარცხნივ). ზემოთ — მიმდინარეობა; **■** — შეჩერება.
5. **თაიმლაინის შენახვა** (ზემოთ) — აირჩიეთ საქაღალდე და სახელი ფანჯარაში „შენახვა როგორც“.
6. **სამონტაჟო პროგრამა:** შენახული ფაილის იმპორტი (*File → Import → Timeline…*). ნიშნის გარეშე —
   ხმით დაემთხვა, **Mango** — კამერის საათით, **Rose** — წყვილი ვერ მოიძებნა.

თითოეული ღილაკი დეტალურად — [docs/gui/user.ka.md](gui/user.ka.md).

## პროგრამის განახლება (კოდის ცვლილების შემდეგ)
პროექტის საქაღალდეში ხელახლა გაუშვით იგივე დაყენების ბრძანება: ის თავიდან ააწყობს Orcaton-ს და
ჩაანაცვლებს დაყენებულ ასლს (ჯერ დახურეთ Orcaton-ის ფანჯარა). პარამეტრები შენარჩუნდება.

## წაშლა
| ოს | როგორ |
|---|---|
| Windows | „პარამეტრები → აპები → **Orcaton** → წაშლა“, ან `powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1` |
| macOS / Linux | `bash scripts/uninstall.sh` |
| Linux, `.deb` / `.rpm`-დან | `sudo apt remove orcaton` / `sudo dnf remove orcaton`; FFmpeg და ბიბლიოთეკები რჩება, პარამეტრები — `~/.config/orcaton`-ში |
| macOS, `.dmg`-დან | „პროგრამის შესახებ“ → **„ტერმინალის ბრძანების წაშლა“** (თუ დაყენებულია), შემდეგ გადაიტანეთ Orcaton Applications-დან Trash-ში; პარამეტრები რჩება `~/Library/Application Support/orcaton`-ში |

იშლება მხოლოდ Orcaton: პროგრამა, მისი მალსახმობები და ბრძანება `orcaton`. Go, Node.js, Wails და FFmpeg
რჩება (მათ შეიძლება სხვა პროგრამებიც იყენებდნენ). `-Purge` / `--purge`-ით წაიშლება პარამეტრები და
ხმის ქეშიც.

## თუ რამე არასწორად წავიდა
| რას ხედავთ | რა უნდა გააკეთოთ |
|---|---|
| `…cannot be loaded because running scripts is disabled` | ბრძანება მთლიანად ჩასვით, დასაწყისში `powershell -ExecutionPolicy Bypass -File`-ით |
| `winget` ვერ მოიძებნა (Windows 10) | Microsoft Store → „App Installer“ → განახლება, შემდეგ გაიმეორეთ |
| `не найдено: go / node` („ვერ მოიძებნა“) ან `… not recognized` დაყენების შემდეგ | დახურეთ ტერმინალი, გახსენით **ახალი** პროექტის საქაღალდეში და გაიმეორეთ ბრძანება (PATH განახლდება) |
| ფანჯარა თეთრი / ცარიელი იხსნება (Windows 10) | WebView2 ძრავა არ არის: `winget install Microsoft.EdgeWebView2Runtime`, შემდეგ ისევ მალსახმობი |
| ფანჯარაში შეტყობინება **FFmpeg არ არის დაყენებული** | დააჭირეთ იქვე **FFmpeg-ის დაყენება** (ან გაუშვით ნაჩვენები ბრძანება ტერმინალში), შემდეგ — **ხელახლა შემოწმება** |
| macOS: „Apple could not verify…“, „ვერ იხსნება, დეველოპერი დადასტურებული არ არის“ | System Settings → Privacy & Security → **Open Anyway** (macOS 12–14: მარჯვენა ღილაკი Orcaton-ზე → Open → Open) — იხ. „macOS: მზა პაკეტი“ |
| macOS: „Orcaton is damaged and can't be opened“ | ხელახლა ჩამოტვირთეთ `.dmg` და შეამოწმეთ `shasum -a 256`; თუ მნიშვნელობა ემთხვევა და შეტყობინება მეორდება — Terminal: `xattr -dr com.apple.quarantine /Applications/Orcaton.app` |
| Ubuntu: `libwebkit2gtk-4.1` ვერ მოიძებნა | Ubuntu 22.04-ზე ძველი არ გამოდგება: საჭიროა 22.04 ან უფრო ახალი |
| სხვა რამ | „დეველოპერისთვის“ → **ჟურნალის კოპირება** Orcaton-ის ფანჯარაში და ტექსტი ტერმინალიდან — დეველოპერს |

## ფანჯრის გარეშე: ტერმინალი
იგივე შესაძლებლობები ხელმისაწვდომია ბრძანებით `orcaton` (იგივე დაყენებით ყენდება) — სკრიპტებისთვის,
ანალიზისა და პაკეტური მუშაობისთვის: `orcaton --help`; ყველა პარამეტრი — [docs/go/usage.md](go/usage.md)
(რუსულად).
