[English](user.md) · [Deutsch](user.de.md) · **Русский** · [ქართული](user.ka.md)

> **Статус: альфа.** Окно уже работает: открыть таймлайн → найти медиа →
> синхронизировать → сохранить. Пометка *(позже)* — то, чего в окне пока нет. Всё то же самое делает
> терминал — [docs/go/usage.md](../go/usage.md). **Терминал остаётся**: окно и `orcaton sync` работают
> на одном ядре и дают одинаковый результат.

## Как открыть окно
Orcaton с окном — **отдельное приложение ОС**: открывается собственное окно программы (значок в панели
задач, Alt+Tab, обычные кнопки свернуть/закрыть). Это **не сайт и не страница браузера**: всё, что
показывает программа, — внутри её окна. Если вы открыли Orcaton в браузере (например, адрес
`http://localhost:…` из вывода терминала при разработке), страница покажет предупреждение «Откройте
Orcaton как программу» и ничего делать не будет: из браузера нельзя ни выбрать файлы на компьютере, ни
запустить синхронизацию.

**Установка** — одна команда в терминале в папке проекта; по шагам для Windows, macOS и Ubuntu —
[docs/quickstart.ru.md](../quickstart.ru.md):
```powershell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Run      # Windows 10/11
```
```bash
bash scripts/install.sh --run                                        # macOS, Ubuntu / Linux
```
Команда ставит недостающее (Go, Node.js, Wails, FFmpeg; в Linux — библиотеки окна), собирает Orcaton из
исходников, устанавливает для вашего пользователя и открывает. Повторный запуск обновляет программу;
настройки сохраняются.

**Запуск** — как у любой программы, без терминала:

| ОС | Где Orcaton | Файл программы |
|---|---|---|
| Windows | **Orcaton** в меню «Пуск» и на рабочем столе | `%LOCALAPPDATA%\Programs\Orcaton\orcaton-gui.exe` |
| macOS | Launchpad / Spotlight «Orcaton», Finder → `~/Applications` | `~/Applications/Orcaton.app`; из `.dmg` — `/Applications/Orcaton.app` |
| Ubuntu / Linux | меню приложений → **Orcaton** | `~/.local/share/orcaton/orcaton-gui`; из пакета — `/usr/bin/orcaton-gui` |

**Удаление** — Windows: «Параметры → Приложения → Orcaton» (или `scripts\uninstall.ps1`); macOS, Linux:
`bash scripts/uninstall.sh`. Удаляется только Orcaton; Go, Node.js, Wails и FFmpeg остаются.

## Язык
Внизу левой колонки (значок глобуса) — **English**, **Deutsch**, **Русский**, **ქართული**. Подписи
меняются сразу, без перезапуска; выбор запоминается между запусками (файл `gui.json` рядом с вашим
`orcaton.toml`). По умолчанию — English. Ниже названия кнопок — как в окне на русском.

## Файлы и папки выбираете вы
Программа сама ничего не выбирает за вас: каждый путь — **системный диалог** Windows / macOS / Linux
(тот же, что в других программах), где вы проходите по папкам и выбираете нужное. Закрыли диалог
(«Отмена») — ничего не происходит.

| Где в окне | Что откроется | Что вы выбираете |
|---|---|---|
| Импорт → блок **Перетащите XML / DRT или выберите…** (клик по всему блоку), большой блок в центре пустого окна, **Заменить…** | диалог «Открыть» с фильтром `*.xml; *.drt` | файл таймлайна (папку — по пути в диалоге); можно и перетащить файл в окно |
| Импорт → **+ Добавить папку** | диалог выбора папки | папку, где лежат исходники; поиск — по имени файла во всех её подпапках |
| **Не найдено файлов: N → Найти…** и диалог «Не найдено медиафайлов» → **Выбрать папку…** | диалог выбора папки | папку с ненайденными файлами («Пропустить» — не искать, «Отмена» — отменить) |
| **Сохранить таймлайн** (вверху после синхронизации) | диалог «Сохранить как» | папку и имя выхода; формат — как у входа (`.xml` → `.xml`, `.drt` → `.drt`); предлагается `<вход> - synced.<ext>` рядом с входом — можно сменить и папку, и имя |
| **Сохранить отчёт (CSV)** | диалог «Сохранить как» | папку и имя отчёта; предлагается `<выход>_report.csv` |
| Настройки → **Папка кэша → Выбрать…** | диалог выбора папки | папку кэша звука (пусто — системная) |
| тост **Показать в папке**, «Для разработчика» → **Открыть папку журналов** | Проводник / Finder | — (только показывает папку) |

Без диалога программа берёт пути только из того, что вы сами указали раньше: папки поиска и настройки
из `orcaton.toml` (Настройки, `orcaton config`) и пути медиа, записанные в таймлайне.

## Коротко: из монтажной программы и обратно
1. **Монтажная программа:** одна камера или рекордер — одна дорожка; экспорт таймлайна
   (*File → Export → Timeline…*) → **FCP 7 XML V5** (`.xml`) или **DRT** (`.drt`).
2. **Orcaton:** перетащите файл в окно или нажмите **Импорт → выберите…** и укажите его в диалоге. Если
   часть медиа не найдена — **+ Добавить папку** и укажите в диалоге папку, где лежат исходники.
3. Нажмите **Синхронизировать** (зелёная кнопка внизу слева). Следите за прогрессом вверху; **■**
   (остановить синхронизацию) — отменить (ничего не меняется).
4. **Сохранить таймлайн** → в диалоге выберите папку и имя (предлагается `Timeline 1 - synced.xml` или
   `.drt` — в формате входа, рядом с ним); по желанию **Сохранить отчёт (CSV)**.
5. **Монтажная программа:** импорт сохранённого файла (*File → Import → Timeline…*).

## Окно
```
┌──────── прогресс: шаг, файл, %, прошло / осталось · после синхронизации — итог и «Сохранить» ────────┐
│ О программе        │  Таймлайн | Файлы     До | После     масштаб · Вписать                          │
│ Настройки          │                                                                                │
│ Импорт  ◀ по умолч.│  таймлайн: строка на камеру, клипы цветом состояния                             │
│ ── Для разработчика│  или таблица файлов                                                            │
│ Русский ▾          │                                                                                │
│ [Синхронизировать]■│  легенда-фильтр: По звуку · По часам камеры · Без пары · Нет на диске           │
└────────────────────┴────────────────────────────────────────────────────────────────────────────────┘
```
* **Левая колонка** — разделы: **Импорт** (что синхронизируем), **Настройки**, **О программе**,
  **Для разработчика** (отладка; виден, пока программа в пре-альфе). Внизу — язык и
  **Синхронизировать** / **■**.
* **Справа** — два вида с переключателем: **Таймлайн** (строка на камеру; камера = дорожка + папка,
  например «6D · V1+A1») и **Файлы** (таблица). **До / После** — исходные места или результат. До
  синхронизации открывается **Файлы**, после — **Таймлайн · После**; дальше окно помнит ваш выбор.

## Импорт: таймлайн и медиа
* Файл: имя, формат, к/с, дорожки, клипы, файлы. **Заменить…** — открыть другой.
* **Папки медиа** — где искать исходники, если пути в таймлайне не находятся (проект с другого
  компьютера, переезд на другой диск). Поиск — по имени файла во всех подпапках (до 6 уровней,
  `PRIVATE/M4ROOT/CLIP` у Sony находится). Одинаковые имена в разных папках различаются по папкам в
  конце исходного пути; если различить нельзя — окно покажет варианты.
* **Оригиналы камер** — если на таймлайне прокси (ProRes из монтажной программы): папки оригиналов камер,
  чтобы взять время съёмки (у прокси его нет). *(позже в окне; пока — ключ `originals` в `orcaton.toml`,
  его окно читает.)*
* **Состояние медиа:** найдено / не найдено / офлайн. Не найдено > 0 — жёлтый блок с **Найти…**.

**Диалог «Не найдено медиафайлов: N»** (появляется и перед синхронизацией, если что-то не найдено):
**Выбрать папку…** — искать ещё в папке; **Пропустить** — оставшиеся встанут в самый конец таймлайна как
«нет на диске» (в монтажной программе — офлайн, перелинкуете потом); **Отмена** — не начинать.

## Результат
Вверху — «✓ Готово за 37 с» и счётчики. Цвет **и** значок у каждого файла:

| В окне | В монтажной программе после импорта | Значит |
|---|---|---|
| ✓ По звуку (зелёный) | без метки | синхронизирован **по звуку**, точность — кадр |
| ◷ По часам камеры (янтарный) | метка **Mango** | поставлен **по часам камеры** — звук не подтвердил (≈ 1 с) |
| ✕ Без пары (розовый) | метка **Rose** | пару не нашёл — стоит по времени съёмки |
| ⌀ Нет на диске (пунктир) | офлайн-клип в конце | файла нет на диске |

* Порядок файлов камеры — по номеру в имени (MVI_0001, C0001, 00001…), затем по времени съёмки;
  номера разных камер не сравниваются (у 6D и 6D2 своя нумерация).
* Файлы без пары не идут одновременно с другими файлами без пары по звуку (настройка **Раскладка без
  пары**, по умолчанию *Друг за другом*): встают рядом с соседями своей камеры, при нужде добавляется
  время; синхронные отрезки не меняются. *Стопкой по камерам* — как раньше.
* Файлы без пары — по этому порядку своей камеры, рядом с соседями (в том числе внутри синхронного
  отрезка); в самый конец — только файлы, которых нет на диске (перед синхронизацией окно спросит, где их
  искать: **Выбрать папку…** или **Пропустить** — тогда в конец); пустот нет.
* Клик по файлу — карточка: камера, позиция (TC), длительность, пара, уверенность, время записи,
  **причина** (почему не по звуку).
* **Файлы**: сортировка по колонкам, поиск по имени, фильтр по итогу — начните с **Без пары**.
* **Синхронизировать** снова — новый прогон с текущими настройками (повтор быстрый: звук берётся из кэша).

## Сохранение
* **Сохранить таймлайн** — в формате входа, без конвертации: открыт `.xml` — сохраняется `.xml`, открыт
  `.drt` — `.drt` (меняются только позиции клипов, длительность и имя таймлайна, остальное — как было).
  Перевести DRT в XML можно в терминале (`orcaton sync in.drt out.xml`). Папку и имя выбираете в
  диалоге «Сохранить как»; предлагается `<вход> - synced.<ext>` рядом с входом.
  Переключатель **Сохранять исходные пути медиа** (Настройки) — записать исходные пути (если результат
  откроют на исходном компьютере).
* В `.drt` метки Rose/Mango пока не пишутся — окно предложит сохранить отчёт.
* **Сохранить отчёт (CSV)** — таблица по каждому файлу (открывается в Excel). **Показать в папке** —
  открыть папку.

## Настройки
Каждое поле — то же, что опция терминала (подсказка у поля). **Сбросить по умолчанию** — вернуть всё.
Неверное значение подсвечивается под полем. Настройки сохраняются между запусками — сразу после
правки, в файл `orcaton.toml` пользователя (путь — внизу раздела).

| Группа · поле в окне | Опция `orcaton sync` | По умолчанию |
|---|---|---|
| Файлы без пары · Размещение | `--unsynced order_time\|edges\|end\|remove` | order_time (По порядку камеры) |
| Файлы без пары · Порядок камеры | `--order-by name\|time` | name (Сначала номер файла) |
| Файлы без пары · Раскладка без пары | `--singles sequential\|stacked` | sequential (Друг за другом) |
| Файлы без пары · Метка / Метка «только часы» | `--label`, `--time-label` | Rose, Mango |
| Сопоставление звука · Источник звука | `--audio-mode mix\|first_stream\|first_channel` | mix (Смешать все каналы) |
| Сопоставление звука · Мин. уверенность / Поднимать порог до шума проекта | `--min-conf`, `--no-auto-threshold` | 12, вкл. |
| Сопоставление звука · Мин. отношение / Мин. перекрытие / Макс. сдвиг | `--min-ratio`, `--min-overlap`, `--max-offset` | 1.5, 2 с, без ограничения |
| Часы камеры · Учитывать время съёмки / Сохранять порядок файлов камеры / Сравнивать клипы одной дорожки | `--no-record-time`, `--no-file-order`, `--intra-lane` | вкл., вкл., выкл. |
| Промежутки · Убирать промежутки длиннее / Оставлять | `--max-gap`, `--keep-gap` | 0 (все), 0 |
| Производительность · Параллельных декодеров / Потоков / Предел памяти | `-j`, `--threads`, `--mem-limit` | авто: ½ ядер (HDD ≤ 4), все ядра, ¾ ОЗУ 1…7 ГБ |
| Производительность · Папка кэша | `--cache` | системная |
| Импорт · Папки медиа | `--map ПАПКА`, `--search` | — |
| Импорт · Оригиналы камер | `--originals` | — |
| Сохранение · Сохранять исходные пути медиа | `--keep-paths` | выкл. |
| Сохранить отчёт | `--report` | для `.drt` — всегда |

Настройки окна и терминала — общие: файл `orcaton.toml` пользователя и рядом с таймлайном
([usage.md](../go/usage.md#файл-настроек-orcatontoml)); что изменено в окне, действует и в `orcaton sync`.
Язык окна — не настройка терминала: он хранится в `gui.json`.

## О программе и «Для разработчика»
* **О программе:** версия программы, FFmpeg (путь и версия; предупреждение, если старше 4.4), кэш звука (папка, размер, **Очистить
  кэш**), лицензии. macOS: **«Командная строка»** — **«Установить команду для терминала»** / **«Удалить команду из
  терминала»**: команда `orcaton` в Терминале (`/usr/local/bin/orcaton` — ссылка на программу внутри Orcaton.app; macOS
  спросит пароль). Доступно, когда Orcaton запущен из папки «Программы».
* **Для разработчика:** журнал событий синхронизации (копировать), папка журналов окна
  (`%LocalAppData%\orcaton\logs`), кэш.

## Вопросы
**Окно пишет «FFmpeg не установлен».** Orcaton читает звук через FFmpeg — бесплатную программу, которая
ставится отдельно. Нажмите **Установить FFmpeg**: окно сначала покажет точную команду и поставит FFmpeg
менеджером пакетов системы — winget в Windows, Homebrew в macOS, apt / dnf / pacman / zypper в Linux (спросит
пароль). Потом само проверит снова. Если кнопки нет (нет winget, Homebrew или графического запроса пароля),
выполните показанную команду в терминале и нажмите **Проверить снова**; на Mac без Homebrew сначала
поставьте Homebrew (brew.sh). Можно указать Orcaton любую папку с FFmpeg переменной `ORCATON_FFMPEG_DIR`.
Подходит любой FFmpeg 4.4 и новее; на более старом окно предупредит. Открыть таймлайн можно и без FFmpeg,
синхронизировать — нет. Другие ошибки установки и запуска —
[quickstart.ru.md](../quickstart.ru.md#если-что-то-пошло-не-так).

**Долго в первый раз.** Звук каждого файла читается целиком один раз, дальше — из кэша. Если
параллельно работает монтажная программа — уменьшите **Потоков**.

**Много «Без пары».** Посмотрите причину в карточке: нет общего звука, перекрытие < 2 с, тишина. Для
прокси укажите **Оригиналы камер** — файлы встанут по часам камеры.
