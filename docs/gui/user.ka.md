## როგორ გავხსნათ ფანჯარა
Orcaton ფანჯრით — **ცალკე პროგრამაა**: იხსნება პროგრამის საკუთარი ფანჯარა (ხატულა ამოცანების პანელში,
Alt+Tab, ჩაკეცვისა და დახურვის ჩვეულებრივი ღილაკები). ეს **არც საიტია და არც ბრაუზერის გვერდი**: ყველაფერი,
რასაც პროგრამა აჩვენებს, მის ფანჯარაშია. თუ Orcaton ბრაუზერში გახსენით (მაგალითად, მისამართი
`http://localhost:…` დეველოპმენტის დროს ტერმინალის გამონატანიდან), გვერდზე გამოჩნდება გაფრთხილება
„გახსენით Orcaton როგორც პროგრამა“ და არაფერს გააკეთებს: ბრაუზერიდან ვერც კომპიუტერზე ფაილებს აირჩევთ
და ვერც სინქრონიზაციას გაუშვებთ.

**დაყენება** — ერთი ბრძანება ტერმინალში პროექტის საქაღალდეში; ნაბიჯ-ნაბიჯ Windows-ის, macOS-ისა და
Ubuntu-სთვის — [docs/quickstart.ka.md](../quickstart.ka.md):
```powershell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Run      # Windows 10/11
```
```bash
bash scripts/install.sh --run                                        # macOS, Ubuntu / Linux
```
ბრძანება აყენებს იმას, რაც აკლია (Go, Node.js, Wails, FFmpeg; Linux-ზე — ფანჯრის ბიბლიოთეკებს), აწყობს
Orcaton-ს საწყისი კოდიდან, აყენებს თქვენი მომხმარებლისთვის და ხსნის. ხელახალი გაშვება პროგრამას
განაახლებს; პარამეტრები შენარჩუნდება.

**გაშვება** — როგორც ნებისმიერი პროგრამის, ტერმინალის გარეშე:

| ოს | სად არის Orcaton | პროგრამის ფაილი |
|---|---|---|
| Windows | **Orcaton** მენიუში „Start“ და სამუშაო მაგიდაზე | `%LOCALAPPDATA%\Programs\Orcaton\orcaton-gui.exe` |
| macOS | Launchpad / Spotlight „Orcaton“, Finder → `~/Applications` | `~/Applications/Orcaton.app`; `.dmg`-დან — `/Applications/Orcaton.app` |
| Ubuntu / Linux | აპლიკაციების მენიუ → **Orcaton** | `~/.local/share/orcaton/orcaton-gui`; პაკეტიდან — `/usr/bin/orcaton-gui` |

**წაშლა** — Windows: „პარამეტრები → აპები → Orcaton“ (ან `scripts\uninstall.ps1`); macOS, Linux:
`bash scripts/uninstall.sh`. იშლება მხოლოდ Orcaton; Go, Node.js, Wails და FFmpeg რჩება.

## ენა
მარცხენა სვეტის ქვემოთ (გლობუსის ხატულა) — **English**, **Deutsch**, **Русский**, **ქართული**. წარწერები
მაშინვე იცვლება, გადატვირთვის გარეშე; არჩევანი გაშვებებს შორის ინახება (ფაილი `gui.json` თქვენი
`orcaton.toml`-ის გვერდით). ნაგულისხმევად — English. ქვემოთ ღილაკების სახელები ისეა, როგორც ქართულ ფანჯარაში.

## ფაილებსა და საქაღალდეებს თქვენ ირჩევთ
პროგრამა თქვენს მაგივრად არაფერს ირჩევს: ყოველი გზა — Windows / macOS / Linux-ის **სისტემური ფანჯარაა**
(იგივე, რაც სხვა პროგრამებში), სადაც საქაღალდეებში გადადიხართ და საჭიროს ირჩევთ. ფანჯარა დახურეთ
(„გაუქმება“) — არაფერი ხდება.

| სად ფანჯარაში | რა გაიხსნება | რას ირჩევთ |
|---|---|---|
| იმპორტი → ბლოკი **გადმოიტანეთ XML / DRT ან აირჩიეთ…** (დაწკაპუნება მთელ ბლოკზე), დიდი ბლოკი ცარიელი ფანჯრის ცენტრში, **შეცვლა…** | ფანჯარა „გახსნა“ ფილტრით `*.xml; *.drt` | თაიმლაინის ფაილს (საქაღალდეს — ფანჯარაში გზით); ფაილის ფანჯარაში გადმოტანაც შეიძლება |
| იმპორტი → **+ საქაღალდის დამატება** | საქაღალდის არჩევის ფანჯარა | საქაღალდეს, სადაც საწყისი ფაილებია; ძებნა ფაილის სახელით მის ყველა ქვესაქაღალდეში |
| **ვერ მოიძებნა N ფაილი → მოძებნა…** და ფანჯარა „ვერ მოიძებნა N მედიაფაილი“ → **საქაღალდის არჩევა…** | საქაღალდის არჩევის ფანჯარა | საქაღალდეს ვერნაპოვნი ფაილებით („გამოტოვება“ — არ ეძებოს, „გაუქმება“ — გააუქმოს) |
| **თაიმლაინის შენახვა** (ზემოთ, სინქრონიზაციის შემდეგ) | ფანჯარა „შენახვა როგორც“ | შედეგის საქაღალდეს და სახელს; ფორმატი — როგორც შესავალს (`.xml` → `.xml`, `.drt` → `.drt`); შემოთავაზებულია `<შესავალი> - synced.<ext>` შესავლის გვერდით — შეიძლება საქაღალდისა და სახელის შეცვლა |
| **ანგარიშის შენახვა (CSV)** | ფანჯარა „შენახვა როგორც“ | ანგარიშის საქაღალდეს და სახელს; შემოთავაზებულია `<შედეგი>_report.csv` |
| პარამეტრები → **ქეშის საქაღალდე → არჩევა…** | საქაღალდის არჩევის ფანჯარა | ხმის ქეშის საქაღალდეს (ცარიელი — სისტემური) |
| შეტყობინება **საქაღალდეში ჩვენება**, „დეველოპერისთვის“ → **ჟურნალების საქაღალდის გახსნა** | Explorer / Finder | — (მხოლოდ აჩვენებს საქაღალდეს) |

ფანჯრის გარეშე პროგრამა გზებს მხოლოდ იქიდან იღებს, რაც თქვენ თავად მიუთითეთ ადრე: ძებნის საქაღალდეები და
პარამეტრები `orcaton.toml`-იდან (პარამეტრები, `orcaton config`) და თაიმლაინში ჩაწერილი მედიის გზები.

## მოკლედ: სამონტაჟო პროგრამიდან და უკან
1. **სამონტაჟო პროგრამა:** ერთი კამერა ან ჩამწერი — ერთი ტრეკი; თაიმლაინის ექსპორტი
   (*File → Export → Timeline…*) → **FCP 7 XML V5** (`.xml`) ან **DRT** (`.drt`).
2. **Orcaton:** გადმოიტანეთ ფაილი ფანჯარაში ან დააჭირეთ **იმპორტი → აირჩიეთ…** და მიუთითეთ ის ფანჯარაში.
   თუ მედიის ნაწილი ვერ მოიძებნა — **+ საქაღალდის დამატება** და ფანჯარაში მიუთითეთ საქაღალდე, სადაც
   საწყისი ფაილებია.
3. დააჭირეთ **სინქრონიზაცია** (მწვანე ღილაკი ქვემოთ მარცხნივ). მიმდინარეობას ზემოთ ადევნეთ თვალი;
   **■** (სინქრონიზაციის შეჩერება) — გაუქმება (არაფერი იცვლება).
4. **თაიმლაინის შენახვა** → ფანჯარაში აირჩიეთ საქაღალდე და სახელი (შემოთავაზებულია
   `Timeline 1 - synced.xml` ან `.drt` — შესავლის ფორმატში, მის გვერდით); სურვილისამებრ
   **ანგარიშის შენახვა (CSV)**.
5. **სამონტაჟო პროგრამა:** შენახული ფაილის იმპორტი (*File → Import → Timeline…*).

## ფანჯარა
```
┌────── მიმდინარეობა: ნაბიჯი, ფაილი, %, გავიდა / დარჩა · სინქრონიზაციის შემდეგ — შედეგი და შენახვა ──────┐
│ პროგრამის შესახებ   │  თაიმლაინი | ფაილები     მანამდე | შემდეგ     მასშტაბი · მორგება                │
│ პარამეტრები         │                                                                              │
│ იმპორტი  ◀ ნაგულისხ.│  თაიმლაინი: სტრიქონი თითო კამერაზე, კლიპები მდგომარეობის ფერით                 │
│ ── დეველოპერისთვის  │  ან ფაილების ცხრილი                                                          │
│ ქართული ▾           │                                                                              │
│ [სინქრონიზაცია] ■   │  ლეგენდა-ფილტრი: ხმით დაემთხვა · კამერის საათით · წყვილი არ აქვს ·             │
│                     │  დისკზე არ არის                                                              │
└─────────────────────┴──────────────────────────────────────────────────────────────────────────────┘
```
* **მარცხენა სვეტი** — განყოფილებები: **იმპორტი** (რას ვასინქრონებთ), **პარამეტრები**, **პროგრამის
  შესახებ**, **დეველოპერისთვის** (გამართვა; ჩანს, სანამ პროგრამა პრე-ალფაშია). ქვემოთ — ენა და
  **სინქრონიზაცია** / **■**.
* **მარჯვნივ** — ორი ხედი გადამრთველით: **თაიმლაინი** (სტრიქონი თითო კამერაზე; კამერა = ტრეკი +
  საქაღალდე, მაგალითად „6D · V1+A1“) და **ფაილები** (ცხრილი). **მანამდე / შემდეგ** — საწყისი ადგილები ან
  შედეგი. სინქრონიზაციამდე იხსნება **ფაილები**, შემდეგ — **თაიმლაინი · შემდეგ**; შემდგომ ფანჯარას თქვენი
  არჩევანი ახსოვს.

## იმპორტი: თაიმლაინი და მედია
* ფაილი: სახელი, ფორმატი, კადრი/წმ, ტრეკები, კლიპები, ფაილები. **შეცვლა…** — სხვის გახსნა.
* **მედიის საქაღალდეები** — სად ვეძებოთ საწყისი ფაილები, თუ თაიმლაინის გზები ვერ მოიძებნა (პროექტი სხვა
  კომპიუტერიდან, სხვა დისკზე გადატანა). ძებნა ფაილის სახელით ყველა ქვესაქაღალდეში (6 დონემდე, Sony-ს
  `PRIVATE/M4ROOT/CLIP` მოიძებნება). ერთნაირი სახელები სხვადასხვა საქაღალდეში საწყისი გზის ბოლოში
  არსებული საქაღალდეებით განირჩევა; თუ გარჩევა შეუძლებელია — ფანჯარა ვარიანტებს აჩვენებს.
* **კამერის ორიგინალები** — თუ თაიმლაინზე პროქსია (ProRes სამონტაჟო პროგრამიდან): კამერის ორიგინალების
  საქაღალდეები, გადაღების დროის ასაღებად (პროქსის ის არ აქვს). *(მოგვიანებით ფანჯარაში; ჯერჯერობით —
  გასაღები `originals` ფაილში `orcaton.toml`, რომელსაც ფანჯარა კითხულობს.)*
* **მედიის მდგომარეობა:** ნაპოვნია / ვერ მოიძებნა / ოფლაინ. ვერ მოიძებნა > 0 — ყვითელი ბლოკი ღილაკით
  **მოძებნა…**.

**ფანჯარა „ვერ მოიძებნა N მედიაფაილი“** (ჩნდება სინქრონიზაციამდეც, თუ რამე ვერ მოიძებნა):
**საქაღალდის არჩევა…** — კიდევ ერთ საქაღალდეში ძებნა; **გამოტოვება** — დარჩენილი ფაილები თაიმლაინის
ბოლოში აღმოჩნდება, როგორც „დისკზე არ არის“ (სამონტაჟო პროგრამაში — ოფლაინ, მოგვიანებით დააკავშირებთ);
**გაუქმება** — არ დაიწყოს.

| ◷ კამერის საათით (ქარვისფერი) | ნიშანი **Mango** | დაყენებულია **კამერის საათით** — ხმამ არ დაადასტურა (≈ 1 წმ) |

| ⌀ დისკზე არ არის (წყვეტილი) | ოფლაინ კლიპი ბოლოში | ფაილი დისკზე არ არის |

* კამერის ფაილების რიგი — სახელში არსებული ნომრით (MVI_0001, C0001, 00001…), შემდეგ გადაღების დროით;
  სხვადასხვა კამერის ნომრები არ შედარდება (6D-სა და 6D2-ს თავისი ნუმერაცია აქვთ).
* წყვილის გარეშე ფაილები არ ჟღერს ერთდროულად სხვა ფაილებთან, რომლებსაც ხმით წყვილი არ აქვთ (პარამეტრი
  **განლაგება წყვილის გარეშე**, ნაგულისხმევად *ერთმანეთის მიყოლებით*): დგება თავისი კამერის
  მეზობლებთან, საჭიროებისას ემატება დრო; სინქრონული ბლოკები არ იცვლება. *კამერების მიხედვით დასტად* —
  როგორც ადრე.
* წყვილის გარეშე ფაილები — თავისი კამერის ამ რიგით, მეზობლებთან (სინქრონული ბლოკის შიგნითაც); სულ
  ბოლოში — მხოლოდ ფაილები, რომლებიც დისკზე არ არის (სინქრონიზაციამდე ფანჯარა გკითხავთ, სად ვეძებოთ
  ისინი: **საქაღალდის არჩევა…** ან **გამოტოვება** — მაშინ ბოლოში); სიცარიელეები არ რჩება.
* დაწკაპუნება ფაილზე — ბარათი: კამერა, პოზიცია (TC), ხანგრძლივობა, წყვილი, სანდოობა, ჩაწერის დრო,
  **მიზეზი** (რატომ არა ხმით).
* **ფაილები**: დალაგება სვეტებით, ძებნა სახელით, ფილტრი შედეგით — დაიწყეთ **წყვილი არ აქვს**-ით.
* **სინქრონიზაცია** ხელახლა — ახალი გაშვება მიმდინარე პარამეტრებით (გამეორება სწრაფია: ხმა ქეშიდან
  აიღება).

## შენახვა
* **თაიმლაინის შენახვა** — შესავლის ფორმატში, კონვერტაციის გარეშე: გახსნილია `.xml` — ინახება `.xml`,
  გახსნილია `.drt` — `.drt` (იცვლება მხოლოდ კლიპების პოზიციები, ხანგრძლივობა და თაიმლაინის სახელი,
  დანარჩენი რჩება). DRT-ის XML-ად გადაყვანა ტერმინალში შეიძლება (`orcaton sync in.drt out.xml`).
  საქაღალდეს და სახელს ფანჯარაში „შენახვა როგორც“ ირჩევთ; შემოთავაზებულია `<შესავალი> - synced.<ext>`
  შესავლის გვერდით. გადამრთველი **მედიის საწყისი გზების შენარჩუნება** (პარამეტრები) — ჩაიწეროს საწყისი
  გზები (თუ შედეგს საწყის კომპიუტერზე გახსნიან).
* `.drt`-ში ნიშნები Rose/Mango ჯერ არ იწერება — ფანჯარა ანგარიშის შენახვას შემოგთავაზებთ.
* **ანგარიშის შენახვა (CSV)** — ცხრილი თითოეული ფაილისთვის (იხსნება Excel-ში). **საქაღალდეში ჩვენება** —
  საქაღალდის გახსნა.

## პარამეტრები
თითოეული ველი ტერმინალის ოფციას შეესაბამება (მინიშნება ველთან). **ნაგულისხმევზე დაბრუნება** — ყველაფრის
დაბრუნება. არასწორი მნიშვნელობა ველის ქვემოთ აღინიშნება. პარამეტრები გაშვებებს შორის ინახება — ცვლილებისთანავე,
თქვენს ფაილში `orcaton.toml` (გზა — განყოფილების ბოლოში).

| ჯგუფი · ველი ფანჯარაში | `orcaton sync`-ის ოფცია | ნაგულისხმევი |
|---|---|---|
| ფაილები წყვილის გარეშე · განთავსება | `--unsynced order_time\|edges\|end\|remove` | order_time (კამერის რიგით) |
| ფაილები წყვილის გარეშე · კამერის რიგი | `--order-by name\|time` | name (ჯერ ფაილის ნომერი) |
| ფაილები წყვილის გარეშე · განლაგება წყვილის გარეშე | `--singles sequential\|stacked` | sequential (ერთმანეთის მიყოლებით) |
| ფაილები წყვილის გარეშე · ნიშანი / ნიშანი „მხოლოდ საათი“ | `--label`, `--time-label` | Rose, Mango |
| ხმის შედარება · ხმის წყარო | `--audio-mode mix\|first_stream\|first_channel` | mix (ყველა არხის შერევა) |
| ხმის შედარება · მინ. სანდოობა / ზღვრის აწევა პროექტის ხმაურამდე | `--min-conf`, `--no-auto-threshold` | 12, ჩართ. |
| ხმის შედარება · მინ. ფარდობა / მინ. გადაფარვა / მაქს. წანაცვლება | `--min-ratio`, `--min-overlap`, `--max-offset` | 1.5, 2 წმ, შეზღუდვის გარეშე |
| კამერის საათი · გადაღების დროის გამოყენება / კამერის ფაილების რიგის შენარჩუნება / ერთი ტრეკის კლიპების შედარება | `--no-record-time`, `--no-file-order`, `--intra-lane` | ჩართ., ჩართ., გამორთ. |
| შუალედები · ამოიღოს შუალედები, უფრო გრძელი ვიდრე / დატოვოს | `--max-gap`, `--keep-gap` | 0 (ყველა), 0 |
| წარმადობა · პარალელური დეკოდერები / ნაკადები / მეხსიერების ლიმიტი | `-j`, `--threads`, `--mem-limit` | ავტო: ბირთვების ½ (HDD ≤ 4), ყველა ბირთვი, RAM-ის ¾ 1…7 გბ |
| წარმადობა · ქეშის საქაღალდე | `--cache` | სისტემური |
| იმპორტი · მედიის საქაღალდეები | `--map საქაღალდე`, `--search` | — |
| იმპორტი · კამერის ორიგინალები | `--originals` | — |
| შენახვა · მედიის საწყისი გზების შენარჩუნება | `--keep-paths` | გამორთ. |
| ანგარიშის შენახვა | `--report` | `.drt`-სთვის — ყოველთვის |

მოქმედებს. ფანჯრის ენა ტერმინალის პარამეტრი არ არის — ის `gui.json`-ში ინახება.

* **დეველოპერისთვის:** სინქრონიზაციის მოვლენების ჟურნალი (კოპირება), ფანჯრის ჟურნალების საქაღალდე

## კითხვები
**ფანჯარა წერს „FFmpeg არ არის დაყენებული“.** Orcaton ხმას FFmpeg-ით კითხულობს — ეს უფასო პროგრამაა,
რომელიც ცალკე დგება. დააჭირეთ **FFmpeg-ის დაყენება**: ფანჯარა ჯერ ზუსტ ბრძანებას გაჩვენებთ და FFmpeg-ს
სისტემის პაკეტების მენეჯერით დააყენებს — Windows-ზე winget, macOS-ზე Homebrew, Linux-ზე apt / dnf / pacman /
zypper (პაროლს მოგთხოვთ). შემდეგ თავად შეამოწმებს ხელახლა. თუ ღილაკი არ ჩანს (არ არის winget, Homebrew ან
პაროლის გრაფიკული მოთხოვნა), გაუშვით ნაჩვენები ბრძანება ტერმინალში და დააჭირეთ **ხელახლა შემოწმება**;
Mac-ზე Homebrew-ს გარეშე ჯერ Homebrew დააყენეთ (brew.sh). ცვლადით `ORCATON_FFMPEG_DIR` Orcaton-ს
ნებისმიერი საქაღალდე შეგიძლიათ მიუთითოთ, სადაც FFmpeg დევს. გამოდგება ნებისმიერი FFmpeg 4.4 ან უფრო
ახალი; უფრო ძველზე ფანჯარა გაგაფრთხილებთ. თაიმლაინის გახსნა FFmpeg-ის გარეშეც შეიძლება, სინქრონიზაცია —
არა. დაყენებისა და გაშვების სხვა შეცდომები — [quickstart.ka.md](../quickstart.ka.md#თუ-რამე-არასწორად-წავიდა).

**პირველად დიდხანს გრძელდება.** თითოეული ფაილის ხმა ერთხელ მთლიანად იკითხება, შემდეგ — ქეშიდან. თუ
პარალელურად სამონტაჟო პროგრამა მუშაობს — შეამცირეთ **ნაკადები**.

**ბევრი „წყვილი არ აქვს“.** ნახეთ მიზეზი ბარათში: საერთო ხმა არ არის, გადაფარვა < 2 წმ, სიჩუმე.
პროქსისთვის მიუთითეთ **კამერის ორიგინალები** — ფაილები კამერის საათით დადგება.

*(მოგვიანებით)* ბოლო პროექტები ცარიელ ეკრანზე, ხმის ნამდვილი ტალღა კლიპებზე.
