# Orcaton — установка и первый запуск (Windows, macOS, Ubuntu)

[English](quickstart.md) · [Deutsch](quickstart.de.md) · **Русский** · [ქართული](quickstart.ka.md)

Orcaton — **программа с окном**: открывается как обычное приложение (своё окно, значок в панели задач
или Dock). Браузер не нужен. Ниже — всё по шагам, без опыта работы с терминалом: терминал понадобится
**один раз** — вставить одну команду. Дальше Orcaton запускается ярлыком.

Что нужно: папка проекта на компьютере, интернет на
время установки, 10–20 минут и ~3 ГБ места (компиляторы и библиотеки для сборки). Установщики
могут попросить разрешение: Windows — окно «Разрешить этому приложению вносить изменения?» →
**«Да»**; macOS и Ubuntu — пароль вашей учётной записи (при вводе символы не видны — это нормально).
Повторный запуск команды установки безопасен: что уже стоит, заново не ставится.

## Windows 10 / 11
1. **Откройте PowerShell в папке проекта.** В Проводнике зайдите в папку проекта, щёлкните правой
   кнопкой по пустому месту → **«Открыть в Терминале»** (Windows 11). В Windows 10 — зажмите **Shift**,
   правая кнопка → **«Открыть окно PowerShell здесь»**. В строке приглашения должен быть путь к папке
   проекта, например `PS D:\Projects\Orcaton>`.
2. **Проверьте, что уже стоит.** Вставьте команду (правая кнопка мыши в окне — вставить) и нажмите **Enter**:
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\install.ps1
   ```
   Скрипт ничего сам не ставит, он только проверяет Go, Node.js, WebView2 и Wails CLI. Если чего-то нет, он
   выведет команды. Выполните их **по одной** (окна установщиков, если появятся, — **«Да»**):
   ```powershell
   winget install --id GoLang.Go -e
   winget install --id OpenJS.NodeJS.LTS -e
   winget install --id Microsoft.EdgeWebView2Runtime -e
   go install github.com/wailsapp/wails/v2/cmd/wails@v2.13.0
   ```
   Затем откройте **новое** окно PowerShell в папке проекта и снова выполните команду из пункта 2.
   FFmpeg необязателен: если его нет, окно предложит установить его при первом запуске.
3. **Установка и сборка.** Когда все инструменты на месте, выполните:
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Run
   ```
   Скрипт соберёт программу, создаст ярлыки и откроет окно. Идут строки `== 2/3 Сборка ==` и `== 3/3 Установка ==`.
4. **Готово**, когда откроется окно **Orcaton**, а в терминале — зелёное «Готово». Ярлык **Orcaton**
   теперь есть на рабочем столе и в меню «Пуск»; терминал можно закрыть. Дальше — только ярлык.

### Windows: готовый установщик (.exe)
Если Orcaton пришёл файлом `Orcaton-<версия>-windows-x64-setup.exe` (большинство компьютеров) или
`Orcaton-<версия>-windows-arm64-setup.exe` (Windows на ARM, например ноутбуки на Snapdragon), ничего собирать
не нужно: Go, Node.js и Wails не нужны. Windows 10 или 11.
1. **Запустите установщик** (двойной щелчок). Orcaton бесплатный и не подписан платным сертификатом, поэтому
   Windows может показать «Система Windows защитила ваш компьютер» → **Подробнее** → **Выполнить в любом
   случае**. Затем Windows спросит
   «Разрешить этому приложению вносить изменения на вашем устройстве?» → **Да** (права администратора: Orcaton
   ставится для всех пользователей компьютера).
2. **Параметры:** *Add the orcaton command to PATH* (команда `orcaton` в терминале) и *Desktop shortcut*
   (ярлык на рабочем столе) — обе включены; ярлык в «Пуске» создаётся всегда (для всех пользователей).
3. **Папка:** по умолчанию `C:\Program Files\Orcaton`; **Browse…** — другая папка. На последней странице — *Run Orcaton*.
4. **FFmpeg.** Если окно показывает **«FFmpeg не установлен»** — нажмите **«Установить FFmpeg»** (через winget).

* Обновление — запустите новый установщик (сначала закройте Orcaton; если окно открыто, установщик попросит).
  Настройки остаются.
* Прежнюю копию Orcaton только для вашего пользователя (`%LOCALAPPDATA%\Programs\Orcaton` — старый установщик или
  `scripts\install.ps1`) установщик удаляет сам; настройки остаются — вручную удалять ничего не нужно.
* Проверка скачанного файла: в PowerShell `(Get-FileHash Orcaton-…-setup.exe).Hash` должен вывести то же
  значение, что в файле `.sha256` рядом (регистр букв не важен).
* Если включён **Smart App Control** (Windows 11), неподписанные программы не запускаются совсем; тогда Orcaton
  работает только с выключенным SAC («Безопасность Windows → Управление приложениями/браузером → Smart App Control»).

## macOS (Apple Silicon и Intel)
1. **Homebrew** (менеджер программ; если уже стоит — пропустите). Откройте **Терминал** (Spotlight:
   ⌘ + Пробел → «Терминал») и выполните команду с сайта <https://brew.sh> (одна строка, спросит пароль
   от Mac). В конце Homebrew напишет «Next steps» — выполните две показанные команды `echo …` и `eval …`.
2. **Терминал в папке проекта:** напишите `cd ` (с пробелом), перетащите папку проекта из Finder в окно
   Терминала и нажмите **Enter**.
3. **Команда установки:**
   ```bash
   bash scripts/install.sh --run
   ```
   Если macOS предложит установить **инструменты разработчика (Command Line Tools)** — нажмите
   «Установить», дождитесь конца и **запустите ту же команду ещё раз**.
4. **Готово**, когда откроется окно **Orcaton**. Программа лежит в **~/Applications** («Программы»
   пользователя): найдите её через Launchpad или Spotlight («Orcaton») и закрепите в Dock (правая
   кнопка по значку → «Параметры» → «Оставить в Dock»).

### macOS: готовый пакет (.dmg)
Если Orcaton у вас в виде файла `Orcaton-<версия>-macos-universal.dmg` (один пакет для Apple Silicon и
Intel; macOS 12 Monterey или новее), ничего собирать и ставить в терминале не нужно:
1. **Скопируйте программу.** Двойной щелчок по `.dmg` → откроется окно с **Orcaton** и папкой
   **«Программы»** (Applications) → перетащите **Orcaton** на **«Программы»**. Потом извлеките диск
   (боковая панель Finder → ⏏).
2. **Первый запуск.** Orcaton бесплатный и не подписан платным сертификатом Apple, поэтому macOS
   останавливает первый запуск. Откройте Orcaton из «Программ» → сообщение «Apple не удалось проверить…»
   (или «не удаётся открыть») → **«Готово»** / **«ОК»**. Откройте **«Системные настройки →
   Конфиденциальность и безопасность»**, прокрутите вниз до «Программа Orcaton заблокирована…» →
   **«Всё равно открыть»** → пароль Mac → **«Открыть»**. В macOS 12–14 достаточно: правая кнопка по Orcaton →
   **«Открыть»** → **«Открыть»**. Это нужно один раз (и снова после установки новой версии).
3. **FFmpeg.** Если окно показывает **«FFmpeg не установлен»** — нажмите **«Установить FFmpeg»** (через
   Homebrew, <https://brew.sh>; без Homebrew окно подскажет, что делать).
4. **Команда в терминале (по желанию):** **«О программе» → «Командная строка» → «Установить команду для
   терминала»** (macOS спросит пароль). После этого `orcaton` работает в новом окне Терминала.

Обновить — перетащите новый Orcaton на «Программы» → **«Заменить»**. Проверить скачанный файл: в Терминале
`shasum -a 256 Orcaton-…dmg` должна вывести то же значение, что в файле `.sha256` рядом.

## Ubuntu 22.04 / 24.04 (и другие Linux)
1. **Терминал в папке проекта:** в «Файлах» откройте папку проекта, правая кнопка по пустому месту →
   **«Открыть в терминале»**.
2. **Команда установки** (спросит ваш пароль — символы при вводе не видны, это нормально):
   ```bash
   bash scripts/install.sh --run
   ```
   Скрипт поставит библиотеки окна (GTK, WebKitGTK), FFmpeg, Go, Node.js и Wails, соберёт программу и
   добавит ярлык.
3. **Готово**, когда откроется окно **Orcaton**. Ярлык — в меню приложений (клавиша Super → «Orcaton»);
   его можно добавить в избранное (правая кнопка → «Добавить в избранное»).
Fedora и Arch — та же команда (скрипт использует `dnf` / `pacman`).

### Linux: готовый пакет (.deb / .rpm)
Если Orcaton у вас в виде файла пакета, ничего собирать не нужно. Менеджер пакетов поставит Orcaton вместе
с библиотеками окна (GTK 3, WebKitGTK 4.1); в системе с рабочим столом они обычно уже есть, поэтому пакет
ставится и без интернета. **FFmpeg** в пакет не входит (как на macOS): поставьте его из своего дистрибутива
потом — см. ниже. Откройте терминал в папке с файлом и выполните (спросит пароль):

| Система | Файл | Команда |
|---|---|---|
| Ubuntu 22.04 / 24.04 / 26.04, Debian 12, Linux Mint 21+ | `orcaton_<версия>-1_amd64.deb` | `sudo apt install ./orcaton_<версия>-1_amd64.deb` |
| Fedora 39 и новее | `orcaton-<версия>-1.x86_64.rpm` | `sudo dnf install ./orcaton-<версия>-1.x86_64.rpm` |

* `./` в начале имени файла обязательно — иначе apt / dnf ищет пакет в интернете.
* Orcaton не подписан: если dnf откажет из-за подписи, добавьте к команде `--nogpgcheck`.
* После этого: меню приложений → **Orcaton**; в терминале — команда `orcaton`.
* **FFmpeg:** при первом запуске окно покажет **FFmpeg is not installed** с командой → **Install FFmpeg**
  (спросит пароль; нужен интернет). Или в терминале: `sudo apt install ffmpeg` (Fedora: `sudo dnf install /usr/bin/ffmpeg`).
* Если Orcaton раньше ставили через `bash scripts/install.sh`, сначала удалите ту копию:
  `bash scripts/uninstall.sh` — иначе меню будет открывать старую.
* Обновить — та же команда с новым файлом. Проверить скачанный файл: `sha256sum -c <файл>.sha256`.

## Первая синхронизация
0. **Язык окна:** внизу левой колонки (значок глобуса) выберите **Русский** — подписи сменятся сразу,
   выбор запомнится. Ниже названия кнопок — как в окне на русском.
1. **Монтажная программа:** каждая камера / рекордер — на своей дорожке; экспорт таймлайна
   (*File → Export → Timeline…*) → **DRT (.drt)** или **FCP 7 XML V5 (.xml)**.
2. **Orcaton:** щёлкните по блоку **«Перетащите XML / DRT или выберите…»** — откроется обычное окно выбора файла;
   выберите экспортированный таймлайн (или просто перетащите файл в окно Orcaton).
3. Если медиа лежат не там, где были при монтаже, — **+ Добавить папку** и выберите папку с исходниками
   (поиск по имени во всех подпапках). Можно и позже: перед синхронизацией Orcaton сам спросит.
4. Нажмите зелёную **Синхронизировать** (внизу слева). Вверху — прогресс; **■** — остановить.
5. **Сохранить таймлайн** (вверху) — выберите папку и имя в окне «Сохранить как».
6. **Монтажная программа:** импорт сохранённого файла (*File → Import → Timeline…*). Без метки — совпал по звуку,
   **Mango** — по часам камеры, **Rose** — пары не нашлось.

Подробно о каждой кнопке — [docs/gui/user.ru.md](gui/user.ru.md).

## Обновить программу (после изменений в коде)
Ещё раз выполните ту же команду установки в папке проекта: она пересоберёт Orcaton и заменит
установленную копию (сначала закройте окно Orcaton). Настройки сохранятся.

## Удалить программу
| ОС | Как |
|---|---|
| Windows | «Параметры → Приложения → **Orcaton** → Удалить» или `powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1` |
| Windows, из `.exe` | «Параметры → Приложения → **Orcaton** → Удалить»; галочка *Also remove settings and cache* — удалить и настройки с кэшем |
| macOS / Linux | `bash scripts/uninstall.sh` |
| Linux, из `.deb` / `.rpm` | `sudo apt remove orcaton` / `sudo dnf remove orcaton`; FFmpeg и библиотеки остаются, настройки — в `~/.config/orcaton` |
| macOS, из `.dmg` | «О программе» → **«Удалить команду из терминала»** (если ставили), потом перетащите Orcaton из «Программ» в Корзину; настройки остаются в `~/Library/Application Support/orcaton` |

Удаляется только Orcaton: программа, ярлыки и команда `orcaton`. Go, Node.js, Wails и FFmpeg остаются
(ими могут пользоваться другие программы). С `-Purge` / `--purge` удалятся и настройки, и кэш звука.

## Если что-то пошло не так
| Что видите | Что делать |
|---|---|
| `…cannot be loaded because running scripts is disabled` | команду нужно вставлять целиком, с `powershell -ExecutionPolicy Bypass -File` в начале |
| `winget` не распознан (Windows 10) | Microsoft Store → «Установщик приложений» (App Installer) → «Обновить», затем повторить |
| `не найдено: go / node` или `… not recognized` после установки | закрыть терминал, открыть **новый** в папке проекта и повторить команду (обновится PATH) |
| окно открылось белым / пустым (Windows 10) | нет движка WebView2: `winget install Microsoft.EdgeWebView2Runtime`, затем снова ярлык |
| в окне — плашка **FFmpeg не установлен** | нажать в ней **Установить FFmpeg** (или выполнить показанную команду в терминале), затем **Проверить снова** |
| Windows: «Система Windows защитила ваш компьютер» при запуске установщика | **Подробнее** → **Выполнить в любом случае** (Orcaton не подписан платным сертификатом) |
| macOS: «Apple не удалось проверить…», «не удаётся открыть, разработчик не проверен» | «Системные настройки → Конфиденциальность и безопасность» → **«Всё равно открыть»** (macOS 12–14: правая кнопка по Orcaton → «Открыть» → «Открыть») — см. «macOS: готовый пакет» |
| macOS: «Программа Orcaton повреждена, её не удаётся открыть» | скачайте `.dmg` заново и сверьте `shasum -a 256`; значение совпало, а сообщение повторяется — в Терминале: `xattr -dr com.apple.quarantine /Applications/Orcaton.app` |
| Ubuntu: `libwebkit2gtk-4.1` не найден | Ubuntu старше 22.04 не подходит: нужна 22.04 или новее |
| что-то другое | «Для разработчика» → **Копировать журнал** в окне Orcaton и текст из терминала — разработчику |

## Без окна: терминал
Те же возможности есть командой `orcaton` (ставится той же установкой) — для скриптов, разборов и
пакетной работы: `orcaton --help`; все опции — [docs/go/usage.md](go/usage.md).
