## FFmpeg

Orcaton runs the external programs `ffmpeg` and `ffprobe` as separate processes to read audio and
metadata; it does not link to FFmpeg libraries. **FFmpeg is not included in this repository or in
Orcaton packages**; the user installs it separately. On request, the window installs it
with the operating system's package manager — winget (package `Gyan.FFmpeg`, a GPL build), Homebrew
or the Linux distribution's package — and that FFmpeg comes under the license of its distributor
(the Linux `.deb` / `.rpm` packages of Orcaton declare the distribution's FFmpeg as a dependency, so the
package manager installs it as a separate package together with Orcaton);
see https://ffmpeg.org/legal.html. If a future package ships FFmpeg next to the program, only an
LGPL build will be used, with its license text and a link to its source code.
